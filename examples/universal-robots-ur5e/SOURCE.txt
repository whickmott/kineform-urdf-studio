KineForm changes:
- Flattened the parameterised Xacro description into a compact plain URDF.
- Uses the official UR5e detailed DAE visual meshes and STL collision meshes.
- Uses the official UR5e default kinematic transforms and visual mesh offsets.
- Leaves visual materials unset so embedded DAE materials are preserved.

The UR5e visual DAEs contain their material appearance in Collada data and do
not need separate texture-image assets for the standard model.
